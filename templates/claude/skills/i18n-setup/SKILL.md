# Интернационализация (i18n)

Реализуй i18n с помощью React Intl и переводами в папках `_.i18n/` рядом с компонентами.

## Когда использовать этот навык

Используй, когда:
- Добавляешь текст для пользователей в компоненты
- Создаёшь новые компоненты с переводимым содержимым
- Обновляешь существующие переводы
- Пользователь упоминает переводы, i18n или локализацию

## Система

**Фреймворк**: React Intl (FormatJS)
**Структура**: Переводы в папках `_.i18n/` рядом с компонентами
**Основной язык**: английский (`en.js`): добавляй сначала английский текст, а потом перевод к нему на русский в `ru.js`

## Структура файлов

```
Button/
  index.tsx
  styles.module.css
  _.i18n/
    ru.js             
    en.js             
```

## Формат файла переводов

```javascript
// Button/_.i18n/ru.js
export default {
  'button': {
    'submit': 'Отправить',
    'cancel': 'Отмена',
    'loading': 'Загрузка...',
  }
};
```

**Правила формата**:
- Используй `export default` (не `module.exports`)
- Ключ первого уровня — имя компонента/файла (например, `'button'`, `'card-list'`)
- Ключи второго уровня — ключи переводов в camelCase
- Структура: `{ 'component-name': { 'key': 'value' } }`
- Для числительных используй ICU синтаксис: `{count, plural, one {# элемент} few {# элемента} other {# элементов}}`

## Использование переводов в компонентах

**Импортируй компоненты/хуки React Intl**
```typescript
import {FormattedMessage} from 'react-intl';
```

**Способ 1: Компонент FormattedMessage**
```tsx
export const Button = () => {
  return (
    <button>
      <FormattedMessage id="button.submit" />
    </button>
  );
};
```

**Способ 2: Для плейсхолдеров и атрибутов**
```tsx
export const Input = () => {
  const intl = useIntl();
  
  return (
    <input 
      placeholder={intl.formatMessage({id: 'input.placeholder'})}
      aria-label={intl.formatMessage({id: 'input.label'})}
    />
  );
};
```

## Именование ключей переводов

**Область видимости компонента**: Префикс с именем компонента
```javascript
// CardList/_.i18n/ru.js
module.exports = {
  'card-list': {
    'title': 'Список карт',
    'empty': 'Нет карт',
    'loading': 'Загрузка карт...',
  }
};
```

## Интерполяция (переменные)

**С значениями**
```typescript
// tsx
module.exports = {
  'greeting': {
    'message': 'Привет, {name}!',
    'card-count': 'У вас {count} {count, plural, one {карта} few {карты} other {карт}}',
  }
};

// Использование
<FormattedMessage 
  id="greeting.message"
  values={{name: 'Иван'}}
/>

// Результат: "Привет, Иван!"
```

**С формами множественного числа**
```typescript
// Перевод
module.exports = {
  'item': {
    'count': '{count, plural, =0 {нет элементов} one {# элемент} few {# элемента} other {# элементов}}',
  }
};

// Использование
<FormattedMessage 
  id="item.count"
  values={{count: 5}}
/>

// Результат: "5 элементов"
```

## Лучшие практики

**ДЕЛАЙ:**
- ✅ Создавай `_.i18n/en.js` и `_.i18n/ru.js` рядом с компонентом
- ✅ Используй ключи с областью видимости компонента (`component-name.key`)
- ✅ Используй `export default` со вложенной структурой: `{ 'component-name': { 'key': 'value' } }`
- ✅ Используй FormattedMessage для содержимого JSX
- ✅ Используй useIntl для атрибутов/плейсхолдеров
- ✅ Обрабатывай множественные числа с помощью ICU синтаксиса
- ✅ Держи переводы рядом с компонентами

**НЕ ДЕЛАЙ:**
- ❌ Хардкодь русский текст в компонентах
- ❌ Используй глобальные ключи переводов
- ❌ Храни переводы далеко от компонентов
- ❌ Используй проп `defaultMessage`
- ❌ Обрабатывай множественные числа вручную
- ❌ Помещай переводы в файлы компонентов
- ❌ Используй `module.exports` — используй `export deafult`

## Чек-лист

Перед завершением настройки i18n:
- [ ] Создан файлы `_.i18n/en.js` и `_.i18n/ru.js` (обрати внимание на точку перед i18n)
- [ ] Все тексты для пользователей вынесены в файл `_.i18n/en.js` и `_.i18n/ru.js`
- [ ] Ключи используют область видимости компонента (`component-name.key`)
- [ ] Использован `export default` со вложенной структурой
- [ ] Использованы FormattedMessage или useIntl
- [ ] Не использованы пропсы `defaultMessage`
- [ ] Формы множественного числа обработаны правильно
- [ ] В ru.js добавлен только русский текст
- [ ] В en.js добавлен только английский текст
